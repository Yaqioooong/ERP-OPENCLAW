# 规格：采购任务来源对话绑定

- 规格编号：`011`
- 状态：已实现（2026-11-04）
- 提出人：采购任务使用者
- 日期：2026-11-04
- 关联需求：追溯采购任务由哪个对话发起；解决多个对话各自创建任务时无法按对话归属的问题

## 1. 背景与目标

采购任务当前以 `task_id` 标识业务任务、以 `user_id` 确定归属，任务执行状态独立保存。聊天中创建任务时，前端只能从工具消息里读取 `task_id`；后端无法回答“这个任务来自哪个对话”“这个对话产生过哪些任务”。

当用户在两个对话中分别创建任务时，执行不会串，但来源不可追溯；换设备或删除对话后，任务与对话的关联更弱。本次目标是把“来源对话”作为任务的可选、不可篡改的来源属性记录下来，并提供受权限约束的追溯能力。任务归属、权限、审批、执行和恢复规则不变。

## 2. 用户故事

- 作为采购任务发起人，我希望在任务详情中看到它从哪个对话发起，以便回到原始上下文。
- 作为采购任务发起人，我希望按对话查看该对话产生的任务，以便在多个任务之间切换。
- 作为审批人，我希望在查看任务时了解它是否有对话来源，但不应因此获得聊天正文访问权。
- 作为系统维护者，我希望历史无来源任务保持“未知”，不被猜测回填。

## 3. 业务规则

- 来源对话是任务的“来源”属性，不是任务的所有者；任务归属仍由 `user_id` 和角色决定。
- 一个任务最多有一个来源对话；一个对话可以有多个任务。
- 来源对话只能由服务端确定：聊天入口取当前认证会话；非聊天入口只能绑定经服务端校验属于当前用户的会话；不得信任未经校验的客户端值。
- 通过对话工具创建任务时必须记录来源对话；缺失时应拒绝创建并返回可诊断错误，不得静默生成无来源任务。
- 从任务面板或直接 API 等非聊天入口创建的任务允许没有来源；不得伪造来源。
- 来源对话在任务创建后不可修改；恢复、审批、重试、查询都不得改变来源。
- 来源对话不构成访问控制：任务所有者可以从其他对话恢复自己的任务；审批人查看任务不获得聊天正文。
- 按对话查询任务仅对会话所有者开放；审批人和管理员按任务权限查看单个任务，不获得该对话的任务列表。
- 来源对话被删除后，任务必须保留且仍可恢复；来源标识不得被级联清空；界面应提示来源不可用。不得级联删除任务、审批或订单。
- 历史任务没有来源时保持“未知”；不得根据聊天记录、`task_id` 或用户行为猜测回填。
- 任务详情对有权查看任务的人返回来源标识；会话正文仍必须经过会话归属校验。
- 不得把聊天正文、偏好正文或供应商上下文复制进任务来源字段。

## 4. 验收标准

| 编号 | 场景 | Given | When | Then |
| --- | --- | --- | --- | --- |
| AC-1 | 聊天发起任务记录来源 | 用户 U 在对话 A 中发起采购任务 | 任务创建成功 | 任务来源为 A；创建响应和任务详情均能读到 A；重新查询后仍为 A |
| AC-2 | 两个对话两个任务 | 对话 A、B 分别创建任务 T1、T2 | 分别查看两个任务 | T1 来源为 A，T2 来源为 B；互不覆盖、互不串 |
| AC-3 | 非聊天入口无来源 | 用户从任务面板或直接 API 创建任务，且未提供来源 | 任务创建成功 | 任务来源为空；审批、恢复、执行正常；不得伪造来源 |
| AC-4 | 非本人会话被拒绝 | 用户 U 创建任务并指定不属于 U 的对话 B 或任意未知对话标识 | 服务端处理创建请求 | 拒绝创建；不写入来源；不得把任务挂到他人对话 |
| AC-5 | 聊天入口缺失来源 | 对话工具路径拿不到当前对话标识 | 尝试创建任务 | 拒绝创建并返回可诊断错误；不得生成无来源任务 |
| AC-6 | 来源不可篡改 | 任务 T1 已记录来源 A | 用户从对话 B 恢复、查询或审批 T1 | T1 来源仍为 A；不得改为 B |
| AC-7 | 按对话查询任务 | 对话 A 有任务 T1、T2，对话 B 有任务 T3 | 对话 A 的所有者查询 A 的任务 | 只返回 T1、T2，不返回 T3；按更新时间倒序；支持分页 |
| AC-8 | 按对话查询越权 | 用户 U2 不是对话 A 的所有者 | 查询对话 A 的任务 | 拒绝；不得泄露任务存在性、数量或来源 |
| AC-9 | 审批人查看任务 | 审批人 P 可查看任务 T1，但不是来源对话 A 的所有者 | 打开 T1 详情 | 可查看任务内容；不能读取对话 A 的聊天正文；任务接口不得返回会话消息 |
| AC-10 | 跨对话恢复 | 用户 U 拥有任务 T1，来源为对话 A | 用户从对话 B 恢复 T1 | 允许恢复；T1 来源仍为 A；恢复不要求当前对话等于来源 |
| AC-11 | 会话删除 | 任务 T1 的来源对话 A 被删除 | 查看或恢复 T1 | T1 保留且可恢复；来源标识不被清空；界面提示来源不可用；不级联删除任务、审批或订单 |
| AC-12 | 历史数据兼容 | 存量任务没有来源 | 升级后查询任务 | 来源显示为“未知”；不做猜测回填；任务功能不受影响 |
| AC-13 | 来源展示与返回 | 任务 T1 有来源 A，且 A 仍可访问 | 任务所有者打开 T1 详情或任务面板 | 显示来源对话；提供返回 A 的入口 |
| AC-14 | 来源不可访问 | 任务 T1 有来源 A，但 A 已删除或当前用户无权访问 | 任务所有者打开 T1 详情或任务面板 | 不显示无效的返回入口；显示来源不可用提示 |
| AC-15 | 日志与隐私 | 任务创建、查询、恢复发生 | 记录日志或任务事件 | 只记录 `task_id`、来源标识、用户/请求标识等白名单字段；不记录聊天正文、偏好正文或供应商上下文 |

## 5. 范围

**包含：**

- 记录聊天入口创建任务的来源对话。
- 非聊天入口在来源经服务端归属校验后记录来源；未提供时保持为空。
- 任务创建响应、任务详情返回来源信息。
- 按对话查询当前用户的任务，支持分页。
- 任务面板展示来源，并在可访问时提供返回来源对话的入口；不可访问时给出提示。
- 会话删除后保留任务与来源标识的兼容行为。
- 存量无来源任务的兼容展示与测试。

**不包含（Out of Scope）：**

- 把会话作为任务的所有者、权限边界或级联删除的父实体。
- 按来源对话查询审批人/管理员可见的全部任务。
- 历史任务来源回填或根据聊天记录猜测来源。
- 精确到某一条用户消息的来源（消息级溯源）。
- 把聊天正文、偏好正文或供应商上下文复制到任务记录。
- 修改采购状态图、审批规则、订单执行逻辑或 checkpoint 结构。
- 会话共享、会话转移或跨用户任务协作。

## 6. 约束与依赖

- 涉及模块：采购任务创建入口、任务仓储与查询、任务 API、前端任务面板、会话归属校验。
- 依赖服务：PostgreSQL 保存任务来源；Redis 保存会话与归属；不新增外部依赖。
- 任务来源是逻辑引用，不是数据库外键；会话在 Redis，任务在 PostgreSQL，需在应用层处理会话不存在或已删除的情况。
- 存量任务来源为空，必须保持兼容；不得用历史聊天记录回填。
- 权限模型不变：任务按 `user_id` 与角色授权；会话按会话归属授权；两者不得互相推导。
- 接口变更需保持向后兼容；现有任务创建、查询、恢复和事件流不得回归。

## 8. 验收证据

2026-11-04 实施证据：

- 工具来源捕获：`tests/test_procurement_task_tools.py::test_start_tool_passes_recovered_model_to_runner` 验证聊天工具把 `runtime.context.thread_id` 作为来源传给 Runner，并在结果中返回；`test_start_tool_requires_conversation_context` 验证来源缺失时返回 `CONVERSATION_CONTEXT_MISSING` 且不创建任务。
- 执行与恢复稳定：`tests/test_procurement_recovery.py::test_task_origin_conversation_is_persisted_and_stable` 验证两个对话创建的两个任务来源分别为 `conv-a`、`conv-b`，查询与审批恢复后来源不变。
- 按对话查询：`tests/test_task_repository.py::test_list_by_conversation_is_scoped_and_paginated` 验证按 `user_id + conversation_id` 过滤、更新时间倒序和分页；`tests/test_procurement_auth.py::test_list_tasks_requires_conversation_owner` 验证仅会话所有者可查询，非本人会话返回 403。
- 来源校验：`test_start_task_accepts_owned_conversation_and_returns_origin` 验证本人会话可作为来源并返回 `conversation_available=true`；`test_start_task_rejects_unowned_conversation` 验证他人会话被拒绝且不创建任务。
- 审批人隐私：`test_get_task_origin_is_available_only_to_conversation_owner` 验证审批人可读取任务详情与来源标识，但 `conversation_available=false`，不会获得会话可访问性。
- 会话删除：`tests/test_thread_ownership.py::test_release_removes_owner_after_delete` 与 `tests/test_history_isolation.py::test_delete_session_releases_ownership` 验证删除会话后释放归属 key，来源不再被判定为可访问。
- 历史数据：仓储查询只匹配 `conversation_id`，存量 NULL 任务不参与按对话列表；无回填逻辑。
- 前端：`frontend/src/components/ProcurementTaskPanel.vue` 增加来源对话展示、`conversation_available` 判断和返回入口；`frontend/src/App.vue` 接入返回来源对话；`npm run build` 通过。
